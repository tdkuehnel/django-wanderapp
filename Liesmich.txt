Tests
=====

Für die Tests wird postgresql mit der postgis-Erweiterung
benötigt. Der in der wanderapp/database.py aufgeführte Benutzer muß
auf der Datenbank daß Recht habe, Erweiterungen aktivieren zu können.

Am besten erstellt man ein template auf Datenbankserverebene in
welchem die postgis-Erweiterung von einem postgres superuser
installiert worden ist.

sudo -u postgres psql
create database template_gis owner postgres;
\c template_gis
create extension postgis;
grant connect on template_gis to public;
revoke temporary on database template_gis from public;
alter database template_gis with is_template = true;

Dann wird dieses template mit der aktivierten postgis-Erweiterung als
Grundlage für die Testläufe verwendet, in dem in der Datei
wanderapp/database.py ein TEMPLATE Parameter hinzugeüfgt wird.

DATABASES = {
    'default': {
        'ENGINE': 'django.contrib.gis.db.backends.postgis',
        'NAME': 'e_01_wanderapp',
        'USER': 'postgis',
        'PASSWORD': DATABASE_PW,
        'HOST': '127.0.0.1',
        'PORT': '5434',
        'TEST': {
            'TEMPLATE': 'template_gis',
        }
    }
}
